# Конструктор форм

Простой конструктор динамических форм на Alpine.js. Позволяет создавать формы с условной логикой показа полей. Мне нужно было написать его для рабочей задачи: мы разрабатываем узкоспециализированный конструктор калькуляторов https://kipvalve.online/kvsc .Стили добавлены с помощью нейросети для визуального оформления просто что бы визуально приятно было проверять. В дальнейшем они будут заменены на собственные, адаптированные под панель администратора Laravel.

## Что умеет

- Создавать поля разных типов (radio, ввод с выбором, да/нет, произвольные)
- Настраивать условия показа полей (если выбрано X — показать Y)
- Работать с данными из JSON
- Автокоррекция значений в пределах диапазона

## Структура

```
form-designer/
├── admin.html          # Админка (конструктор)
├── site.html           # Фронтенд (форма для пользователя)
├── css/style.css       # Стили
├── script/
│   ├── admin.js        # Логика админки
│   └── site.js         # Логика фронтенда
├── form-config.json    # Конфиг формы (сохраняется из админки)
└── test-data.json      # Данные для теста
```

## Запуск

Нужен локальный сервер (fetch не работает с file://).

```bash
python3 -m http.server 8000
```

Открыть:
- Админка: http://localhost:8000/admin.html
- Форма: http://localhost:8000/site.html

**НО МОЖНО И ПРОЩЕ !!!**

Например, используйте плагин «Live Server». Важно, чтобы это был не просто просмотр HTML-документа в браузере, иначе тестовая JSON-база не будет считываться из-за ограничений безопасности браузера.

## Как пользоваться

1. В админке создаёшь поля, настраиваешь условия
2. Жмёшь "Сохранить всё" — скачивается JSON
3. Кладёшь его как `form-config.json`
4. Открываешь `site.html` — видишь форму

## Технологии

- HTML/CSS/JS
- Alpine.js (через CDN)
- JSON для конфигов и данных
